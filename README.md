# 🎓 Student Result Management System

A full-stack web app built with Python & Django to manage student records and results.

## Technologies
- Python & Django
- HTML5 & CSS3
- Bootstrap 5
- SQLite Database

## Features
- Student Management
- Subject Tracking
- Result Reports
- Django Admin Panel

## How to Run
pip install django
python manage.py runserver
